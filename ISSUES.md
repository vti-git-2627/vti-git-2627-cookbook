# Starter issues

Copy each of these into the **Issues** tab of your team repository (session 5).
Then each team member assigns themself one. Issues 1 and 2 both change `index.html`,
so the second one to merge will meet a conflict. That is on purpose.

---

## 1. Add a recipe for your favourite dish (one issue per team member)

**Title:** Add recipe: `<dish>`

Copy `recipes/_TEMPLATE.md` to `recipes/<dish>.md`, fill it in, and add a link to it
in the recipe list in `index.html`.

- [ ] New file in `recipes/`
- [ ] Link added to the list in `index.html`
- [ ] Checked on the live site after merging

---

## 2. Add a contributors section to the footer

**Title:** Show contributors in the footer

The footer in `index.html` says "Made by our class". Replace it with a list of the
team's first names (or GitHub usernames), each linking to their GitHub profile.

---

## 3. Fix the broken pancake link

**Title:** Pancake link on home page gives a 404

Clicking "Fluffy pancakes" on the home page shows "Page not found". Find out why and fix it.
(Hint: compare the link with the file name.)

---

## 4. Add a "Difficulty" field to the recipe template

**Title:** Recipes should show difficulty

Add a `Difficulty: easy / medium / hard` line to `recipes/_TEMPLATE.md`
and fill it in for `recipes/pancakes.md`.

---

## 5. Make the site comfortable in dark mode

**Title:** Site is very bright at night

Add a `@media (prefers-color-scheme: dark)` block to `style.css` with darker
background and lighter text colours.

---

## 6. Finish the README

**Title:** README: team section and how to view the site

Fill in the Team list in `README.md` and add the link to the live GitHub Pages site.
