# Class Cookbook

A tiny website where every recipe is added through a pull request.
It is the practice project for our Git & GitHub module: the code is simple on purpose,
so all your attention can go to **how we work together**.

When GitHub Pages is switched on, every merged pull request goes live at
`https://<org-name>.github.io/<repo-name>/`.

## What's in here

| Path | What it is |
| --- | --- |
| `index.html` | The home page with the list of recipes. Everyone edits this file, so expect conflicts. |
| `style.css` | How the site looks. |
| `recipes/` | One Markdown file per recipe. Copy `_TEMPLATE.md` to start a new one. |
| `CONTRIBUTING.md` | Our team rules: branches, pull requests, reviews. Read it first. |
| `ISSUES.md` | Six starter issues to copy into the Issues tab (session 5). |
| `exercises/` | The conflict lab (session 4) and the rescue stations (session 6). |
| `teacher-tools/` | A script that builds a demo repository with an interesting graph. |

## How to contribute (short version)

1. Pick or create an issue and assign yourself.
2. Pull `main`, then create a branch: `recipe/<dish>` or `fix/<what>`.
3. Commit small steps with clear messages.
4. Push and open a pull request. Write `Closes #<issue number>` in the description.
5. Ask a teammate for a review. Fix what they find.
6. Merge, delete the branch, pull `main`.
